# oiioii 新手跟练：交互契约与实测记录

> 来源：在内置浏览器里对 `https://www.oiioii.tv` 的实操（2026-10-08 ~ 10-09）。
> 被测账号 **0 盒饭 / 0 FREE 额度**，跟练全程照样跑完 → **零消耗**，产物全是预置假数据（CDN 现成素材）。
> 本文是「提炼到本地」的版本：主 agent 的实测记录 + 每步机制 + 和我们实现的对照。

## 一、入口与四个方向

| 步骤 | 说明 |
| --- | --- |
| 入口 | 首页右上角**头像（带 FREE 角标）→ 账号菜单 → 「新手跟练」** |
| 方向选择 | 弹出「**选择你的创作方向**」（文案：先选择一个方向，OiiOii 会用对应的新手跟练流程带你从想法开始体验） |
| 四个方向 | 动画创作者 / 短漫剧创作者 / 游戏工作者 / 其他 —— **四个方向各是一套独立跟练** |

| identity 取值 | 实测四套全部跑通：`animation`（动画创作者）、`short_drama`（短漫剧创作者）、`game_fan`（游戏工作者）、`other`（其他） |

## 二、八步清单（逐字抄自右侧「新手引导」面板）

两套已实测的方向**骨架相同**，都是这八步、都带一句小字说明：

1. **输入想法** —— 在输入框里描述你的创意。
2. **确认视频设置** —— 先定好短片基调，确认16:9、中文对白、短片长度和情绪标签。
3. **确认剧本** —— 编剧已根据你的想法生成剧本，请导演审阅调整。
4. **选择角色和场景** —— 设计师已为你设计好角色和场景，确认好后即开启分镜。
5. **确认分镜配置** —— 分镜卡片已准备好，请确认分镜配置。
6. **生成视频** —— 请导演确认好分镜提示词和分镜视频。
7. **确认BGM** —— 音效方案已准备好，请确认音频配置。
8. **合成视频** —— 跟练视频已完成！去首页创作你的第一个作品吧

面板顶部常驻 **「已完成 N/8 步」**；每步左侧图标三态（未到 / 当前 / 已完成打勾）。

## 三、每步的机制（不是浮层教程）

- **形态**：右侧常驻清单 + 左侧一条 **Agent 对话流**，每一步换一位角色说话：**艺术总监 → 编剧 → 角色设计师/场景设计师 → 动画师 → 音效师 → 剪辑师**。
- **每步一个动作**：主按钮只有一个（「确认并继续」/「满意并继续」），旁边永远有 **「我要修改」** 这条退路；点主按钮即把进度推到 N+1。
- **产物是预置的**：清单文案自己写着「编剧**已**根据你的想法生成剧本」「设计师**已**为你设计好角色和场景」「分镜卡片**已**准备好」「音效方案**已**准备好」。实测视频源来自 CDN：`.../newUser-intro/animation/storyboard-1.mp4`。
- **引导从不指向画布元素**：所有提示都在侧栏/弹窗里 —— 所以它**既不需要自动平移画布，也不会遮挡任何东西**（我们的跟练是指着画布元素教的，因此必须保留卡片避让 + 自动定位）。
- **完成后有成果感**：最后一步把「最终视频卡片」落到画布上，工具条出现 `角色 / 场景 / 分镜 / 视频` 与「去剪辑」「下载所有分镜」。
- **过程细节**：步骤 2 的确认面板含 情绪标签（热血/成长/节奏/信任/宁静/随机）、影片长度（短视频 <1min / 长视频 >=1min）、影片比例（16:9/9:16/21:9）、对白语言（中文/英文/日文/…）；步骤 3 的剧本面板带「**一键提取**」抽道具/服装；步骤 7 给一个 BGM 播放器（实测 00:03:42）并问是否合成。

## 五、自动化这件事本身的坑（下次直接用）

1. 画布上盖着一层**全屏透明 `_chat-layer_`（实测 905×1286）**：`document.elementFromPoint` 在任何坐标都返回它 → **坐标点击落不到真实控件上**（CUA 点、合成 MouseEvent 都无效）。只能对 DOM 节点直接 `.click()`。
2. 「确认并继续」那类主按钮**不是 `<button>`**（styled div）→ 按 `button` 找会全军覆没，要按**文本**找。
3. 对话流是**累积的聊天历史**：历史步骤的按钮仍留在 DOM 里 → 必须先**把所有可滚动容器滚到底**，再点「最靠下的那个可见主按钮」，否则会一直点到旧按钮上（表现为进度不动）。
4. 进度探针：`document.body.innerText.match(/已完成\s*(\d+)\/(\d+)\s*步/)`。

## 六、我们照它改了什么 / 明确不抄什么

已实现（跟练升级，见 `docs/` 与提交记录）：
- **常驻八步清单 + 「已完成 N/8 步」+ 点行跳步**（`app/components/canvas/CanvasPracticeList.vue`）；
- **「已为你准备好，请确认」**：进步骤即自动补齐（提示词/模型/参数/节点/连线），主按钮一次「确认并继续」，另给「我要改」退回手动路径；
- 每步一句说明（`PracticeStep.summary`）与进度同屏；
- 最后一步把回放成片以「**成片卡**」留在画布视野中央（带「跟练成片」角标；仍属跟练数据，退出即随快照还原、不落库）。

明确不抄：预置 CDN 素材、Agent 拟人化叙事腔、「进去就出不来」的强绑定；也不引入浮层教程范式（我们的长处是指着画布教：回放、沙盒还原、卡片避让、自动定位）。
