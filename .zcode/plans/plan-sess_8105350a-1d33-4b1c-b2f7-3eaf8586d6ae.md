画布默认节点：角色设计师 + 编剧（演示数据先行）

## 目标
新增两种**不可手动创建**的画布节点类型 `character-designer`（角色设计师）和 `script`（编剧），新建空画布时默认各落一个。卡片内容用演示数据（截图里的滕站长/林北玄/苏小鱼/赵大勇等 + 《仙帝在人间送外卖》剧本）。

## 一、节点类型注册（app/utils/canvas-node-kinds.ts）
- `CanvasNodeKind` 联合类型加 `'character-designer' | 'script'`。
- **不加入** `CANVAS_NODE_ITEMS`（+ 菜单/双击菜单/Agent 面板都不会出现它们，满足「没有任何地方可以创建」）。
- `CANVAS_STAGE_SIZE` 加：`'character-designer': { w: 620, h: 400, minW: 420, minH: 300 }`、`script: { w: 380, h: 460, minW: 280, minH: 320 }`（stage 型节点，带左上角标签）。

## 二、默认落节点（app/pages/canvas/index.vue）
- `runSave` 里 `canvasApi.create` 成功后：若提交的 `graph.nodes` 为空，则构造含两个预置节点的 graph 再调 `canvasApi.save`（或直接在 create 的 graph 参数里带上预置节点 —— 采用后者：`graph.nodes.length === 0` 时用 `withStarterNodes(graph)` 替换后再 create，一次落库，前端同时 `loadGraph` 显示）。
- 预置节点：`script-1`（position 60,80）与 `character-designer-1`（position 520,80），data 只带 kind/label/mode，其余走组件内演示数据。
- 已有画布 / skill 模板 / 导入 / 历史回滚不受影响（只在 create 且空 graph 时注入）。

## 三、演示数据（新文件 app/utils/canvas-demo-cast.ts）
- `DEMO_CAST`：6 个角色 `{ id, name, desc, status: 'ok'|'failed', frontUrl?, fullUrl? }` —— 滕站长(成功)、小刘(失败)、林北玄(成功)、燕绮道侣(成功)、苏小鱼(成功)、赵大勇(失败)，desc 用截图文案；图片先用占位（组件里渐变块 + 角色名首字），URL 字段留空。
- `DEMO_SCRIPT`：`{ title: '我的剧本', genre: '都市脑洞 / 都市修真 | 体量：100-150万字', outline: 截图大纲全文（多段） }`。

## 四、角色设计师节点（新组件 CanvasCharacterDesignerNode.vue）
CanvasNode.vue 中 `isStage` 分支里按 `data.kind === 'character-designer'` 渲染此组件（替代默认 glyph），节点级 class 加 `'is-cast'`。
- 标题行「👤 角色设计师」（节点内顶部，紫色高亮）。
- 2 列网格 6 张卡：
  - 成功卡：左列（名称、描述 3 行截断、「确认/取消」小按钮、音色上传虚线框），右列上下两张图（正面半身/全身，占位渐变+角色名首字），图右下「多视角」小按钮，卡底紫色「加入资产库」按钮 + 圆形编辑按钮。
  - 失败卡：右侧整体黑色方块，居中「生成失败 ⓘ」「盒饭不足，请充值后重试」「盒饭已退回」+「重试」「取消」按钮。
- 交互：
  - 音色上传：`assetApi.upload`（accept audio/*），成功后卡片显示文件名，写节点 data.voices[roleId]（随画布保存）。
  - 加入资产库：`subjectApi.create({ kind: 'character', name, look: desc })`，成功 toast「已加入资产库」，按钮变「已加入」；失败 toast 错误信息。
  - 重试：本地把失败卡切回成功态（演示）；取消：保持失败态并 toast。
  - 点卡片/编辑按钮 → 打开角色弹窗。

## 五、角色弹窗（新组件 CanvasCharacterModal.vue）
- `.studio-modal-mask` + `.studio-modal`（现有模态体系），宽 ~860px。
- 左栏：角色名称输入框、角色描述 textarea、音色上传、「加入资产库」、底部「确认/取消」。
- 右栏大显示区：成功态大图占位；失败态居中「生成失败 + 提示 + 重试/取消」。
- 确认把名称/描述写回节点演示数据（组件本地 ref），取消关闭。

## 六、编剧节点（新组件 CanvasScriptNode.vue）+ 弹窗（CanvasScriptModal.vue）
- 节点：标题「🟣 编剧」；大卡片：标题「我的剧本」+ 复制按钮（navigator.clipboard 复制大纲，toast「已复制」）、类型行、大纲多段文字（内部滚动）、右下「查看 →」。
- 「查看」打开 CanvasScriptModal：完整大纲 + 关闭。

## 七、CSS（app/assets/css/studio-parts/canvas.css 追加）
- `.canvas-cast-node`（网格卡/失败态/按钮）、`.canvas-script-node`、弹窗布局；紫色 accent 用 `#a855f7`（截图同款），其余走 `--st-*` 令牌。节点内滚动 `nowheel`。
