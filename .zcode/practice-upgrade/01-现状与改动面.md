### 结论：要「全程不可编辑」，最少动哪几处

**有现成开关可直接用**（跟练态加进表达式即可，一处集中）：
1. Vue Flow 的三个 prop + 平移：`:nodes-draggable`、`:nodes-connectable`、`:elements-selectable`、`:pan-on-drag`、`:selection-key-code`（Workspace:4576-4584）——把 `canvasLocked` 旁的判断加上「跟练中」即一次关掉拖/连/选/平移（平移要留就单独放行）。`deleteKeyCode` 已是 `null`（:4584），无需再动。
2. 快捷键总闸：`dispatchCanvasShortcut` 的 `readonly` 位（canvas-shortcuts.ts:86、Workspace:2451）——传 `props.readonly || practiceSession.active` 可一刀关掉 Delete/⌘C/⌘V/⌘D/⌘G/⌘L/⌘Z（⌘Enter 已被回放拦）。
3. 右键与双击：`onBlankContext`（:1322-1323）、`onStageDblClick`（:2413）已按 `props.readonly` 早退，跟练态一起带上即可。
4. 空画布起步卡：`CanvasEmpty` 已有 `readonly/canvasLocked` 两个 prop（:64）可直接复用。
5. 工具轨：`v-if="!readonly"`（:4658）可扩展为隐藏/禁用 edit 组；资产落图入口 `openAssetPicker`（:1926）需单独加闸（该函数被对话栏、检查器、工具轨多路调用，是上传 / 落图的收口点）。

**必须新增守卫、没有现成开关的**：
- 节点右键菜单的删除/副本（`removeSelectedNodes` 只看 `canvasLocked`，:1465-1467；`dropNode` :3775 无闸）→ 最省事的做法是把「跟练中」并进 `canvasLocked` 的计算本身，但 `canvasLocked` 还控制 Dock 锁定按钮与 `panOnDrag`，需要确认产品是否要连平移一起关。
- 检查器写入（第 12 行）——这是唯一与「引导要求用户自己填」冲突的一类：`PracticeGate` 的 `prompt/model/edge` 判据正是要用户自己动手（canvas-practice.ts:40-45、剧本 :622/:632/:642/:662 等）。**「画布只读」与现有判据互斥**，要么判据改成纯回放（由引擎自动备好，用户只点「确认并继续」），要么只读范围排除 Inspector。
- 媒体动作 `submitMediaJob` 与图片编辑两处 `taskApi.create`（第 15/16 行）——回放拦不到它们，跟练中会真花点数，必须显式拦。
- 对话栏（第 18 行）——需要把 practice 态传进 `CanvasChat` 或在上层禁用。
- 导入画布文件（第 24 行）——会整张替换画布且毁灭沙盒快照的语义。
- 运行队列重试（第 21 行）——最小做法：跟练中禁用按钮。

## 3. 相机

- 来源：`useVueFlow('easytv-canvas')` 解构 `viewport / setViewport / setCenter / fitView / zoomTo / zoomIn / zoomOut`（Workspace:244-264）。
- `revealPracticeAnchor(overrideNodeId?, wait=0, measure=0)`（host:210-246）：`import.meta.client` + `session.active` 早退（:211-212）；`practiceAnchorElement` 找元素（:249-257，`tools/starts` 锚点直接返回 null 不追）；用 `canvasFlowPaneRect()` 夹 16px 边距算 dx/dy（:219-240）；`opts.setViewport({x: vp.x+dx, y: vp.y+dy, zoom: vp.zoom})`（:243）**瞬移**；收敛用两条递归——元素没渲染时 `requestAnimationFrame` 最多再等 3 帧（`REVEAL_MAX_WAIT_FRAMES=3`，:197、:215-217），位移后面板重排用 `nextTick` 再测一轮（`measure<1`，:244-245）。
- 成片居中：`ensurePracticeShowcase` 的 `opts.setCenter(cx, cy, { zoom: 当前值 })`（host:453），同样瞬移。
- 全仓库唯一的补间：`organizeCanvas` 的 `fitView({ padding: 0.24, duration: 220 })`（Workspace:2862；无参版本 :2852、快捷键 :2466、Dock :4750）。
- 用户改相机的入口（补间该被打断的时刻）：

15. **`spot` 的尺寸按锚点矩形给，不看容器**：`width: Math.min(window.innerWidth - 16, r.width + 16)`（Tour:226）——锚点比窗口宽时会被截断，锚点在 Inspector 展开态下的 `inspector-run` 按钮上时聚光只有按钮大小。
